🌤️ Flutter Weather App

A modern and clean weather application built with Flutter and Stacked Architecture, featuring real-time weather data, sleek UI design, and dynamic Dark/Light mode support.

✨ Features

Real-Time Weather Data: Instantly fetch temperature, humidity, wind speed, atmospheric pressure, visibility, and cloud percentage for any city using the OpenWeatherMap API.

Dark & Light Theme Support: Seamlessly switch between dark and light modes via the settings icon, with user preferences saved locally using SharedPreferences.

Interactive Search: Clean search interface to look up weather details for cities worldwide.

Clean Architecture: Developed using the Stacked Architecture pattern for robust state management and maintainable code structure.

🛠️ Tech Stack

Framework: Flutter & Dart

Architecture: Stacked Architecture

API: OpenWeatherMap API

Local Storage: SharedPreferences

🚀 Getting Started

To run this project locally on your machine:

Clone the repository:

git clone https://github.com/Naba79/Weather-app.git


Install dependencies:

flutter pub get


Run the application:

flutter run
